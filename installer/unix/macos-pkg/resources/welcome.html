scAnt pro @VERSION@ for macOS (Apple Silicon)

This installs scAnt for your user account, without administrator rights, in ~/Library/scAnt, and adds scAnt to the Applications folder in your home folder. It sets up the Python environment, focus stacking (shinestacker, focus-stack, rig_stack), ExifTool, and COLMAP and Brush for Gaussian splatting (COLMAP needs macOS 15 or later).

FLIR cameras: put Teledyne's Spinnaker-4.4.0.246.pkg (or the .dmg that holds it) in your Downloads folder first; the installer finds it there, or asks for it. It then shows Teledyne's licence agreement for you to accept.

Installing needs an internet connection and about 5 GB of disk space. The step Running package scripts downloads the Python environment and the tools and takes a few minutes; scAnt tells you in a dialog when it is done.

A copy of the details is written to ~/Library/scAnt/install.log. To remove scAnt later, run ~/Library/scAnt/uninstall.sh in Terminal.
